# 學國字 ㄅㄆㄇ ・ 長輩友善的中文分級學習工具

一個單一檔案的網頁工具，設計給不熟悉繁體字與注音的長輩使用。
手機打開瀏覽器就能用，不用安裝、不用註冊、不用網路帳號。

**直接使用：** https://ellencheng503.github.io/learn-chinese/

## 怎麼設計的

長輩最怕的是「一堆功能自己去按」。所以這裡**首頁只有一顆主按鈕**：
接著上下一課。不用選、不用逛、不用想今天該練什麼。

```
小學三年級
第 3 課 / 共 8 課
家人

  ▶ 開始第 3 課
  🔁 今日複習 12 個字
```

首頁那顆主按鈕永遠指向「還沒上過的下一課」，所以不想選也可以一路按下去。

## 不認字也能自己操作

如果長輩不太認得字，畫面上的說明文字對他們等於不存在。所以：

- **每進一個畫面，就先用語音講一次現在要做什麼**
  例如進首頁會唸「小學三年級，第三課，家人。要開始，按綠色的按鈕。」
- **說明句講得比生字快**（生字放慢才聽得清楚，說明用正常語速才自然）
  說話速度的設定調的是生字的速度，說明會自動再快一點
- **右上角固定一顆 🔊 喇叭鍵**，位置永遠不變，按下去就把剛才那句話再講一次
- **答對答錯都用講的**，不是只靠顏色：「答對了」／「不對喔，答案是…」
- **小考進度用長條**，不是「3 / 10」這種數字
- 同一種題型連續出現時不重複唸指令，避免聽十遍同一句話
- 句子裡的數字用國字（第三課、答對八題），語音才不會唸成怪腔調

按鈕的顏色也固定當作記號：**綠色 = 往下一步、黃色 = 複習、白色 = 再做一次**，
語音指令會直接說顏色（「按下面綠色的按鈕」）。

## 一堂課的流程

每課 5 個字詞，大約 5 到 8 分鐘。

1. **學** — 圖卡 ＋ 繁體字 ＋ 注音 ＋ 國語發音 ＋ 部件記憶提示
2. **寫** — 米字格描紅，用手指寫一次（可在設定關掉）
3. **考** — 每個字出 2 題，題型交錯，答錯當場給正確答案並唸出來

## 圖卡題只出「看得出來」的字

圖卡題（看圖選字）只出**具體看得見的東西**：物品、食物、地方、數字、身體部位。
凡是人物、表情、抽象概念一律不出圖卡題——
👨 爸爸和 👦 哥哥、👶 妹妹和嬰兒，光看圖根本分不出來，
那種題目答錯不是學習者不會，是題目本身有問題。

國中以上（第 5 級起）用字抽象，圖只是裝飾，整級都不出圖卡題。

目前 250 個字詞中，100 個會出圖卡題、150 個不會。
不出圖卡題的字在**學習卡上還是有圖**（那時字就在旁邊，只是輔助記憶，不會誤導），
而且仍然有「聽音選字」「看字選注音」「看注音選詞」三種題型，練習量不會變少。

## 用到的記憶方法

這些不是隨便排的，每一項都對應一個有實證的學習原理：

| 做法 | 原理 |
| --- | --- |
| 學完立刻考，而不是重看一遍 | **提取練習**：主動回想比重複閱讀有效得多 |
| 答對的字排 1分 → 10分 → 1天 → 2天 → 5天 → 12天 → 30天 後再考 | **間隔重複**：在快要忘記時複習，記得最久 |
| 答錯的字直接退兩格，過幾天一定會再遇到 | 錯誤要被重新編碼，不能只看過答案就算了 |
| 同一課的字混著出、四種題型交錯 | **交錯練習**：比同一題型連續做更能形成長期記憶 |
| 圖 ＋ 字形 ＋ 讀音 ＋ 注音同時出現 | **雙重編碼**：多個感官通道一起記，提取線索更多 |
| 「飯 ＝ 食 ＋ 反，左邊跟吃有關，右邊是聲音」 | **精緻化編碼**：拆成有意義的部件，比死背筆畫省力得多 |
| 用手指在米字格描一次 | **動作記憶**：手寫過的字形記得比只用看的牢 |
| 干擾選項優先取同一課、同字數的詞 | **合意的困難**：選項太好猜等於沒考到 |
| 答錯馬上顯示並唸出正確答案 | **即時回饋**：錯誤停留越久越容易固化 |

## 手機上不用捲動

已在 iPhone SE / 14 / Pro Max 三種尺寸、字級開到最大的情況下實測，

## 其他長輩友善的設計

- 內文 19px 起跳，可放大到 1.3 倍；字卡最大到 80px
- 所有可按的地方最小高度 68px，選項卡片更大
- 每題最多三個選項，不使用滑動手勢、不使用純圖示按鈕
- 返回鍵固定在左上角
- 第一次點擊不會改動版面（避免手指按下後畫面位移導致按空）

## 語音

使用瀏覽器內建的語音合成（Web Speech API），優先選擇 `zh-TW` 台灣國語語音。

- **iPhone / iPad**：Safari 內建中文語音（Mei-Jia），可直接使用
- **Android**：若沒聲音，到「設定 → 系統 → 語言與輸入 → 文字轉語音輸出」下載「中文（台灣）」語音
- 若偵測到兩秒內都沒有真的開始朗讀，畫面上方會自動跳出排除步驟的提示

## 加入 iPhone 主畫面

用 **Safari** 打開網址 → 按下方分享鍵 → 往下滑選「加入主畫面」→ 新增。

主畫面會出現「學國字」圖示，點開是全螢幕、沒有網址列。
這個圖示是獨立開啟的，跟長輩平常慣用哪一個瀏覽器無關，
所以只要用 Safari 做一次這個設定就好。

## 內容說明

- 注音採台灣教育部標準，輕聲以「˙」標在音節前（例：爸爸 ㄅㄚˋ ˙ㄅㄚ）

## 進度會不會不見

所有設定與學習紀錄都只存在手機瀏覽器裡（localStorage），不會上傳到任何地方。

**進度是綁在「裝置 ＋ 瀏覽器」上的，不是綁在人身上。**
沒有帳號也沒有伺服器，所以同一個人在不同裝置、甚至同一台裝置的不同瀏覽器，
都會是各自獨立的一份進度。多個人共用同一支手機的同一個瀏覽器，則會共用同一份。

**網頁改版不會影響進度。** 儲存用的名稱固定是 `twlearn`，不會再改；
舊版本用過的名稱（`twlearn.v2`、`twlearn.v1`）會被自動讀取並搬過來，
連 v1 時代的練習次數都會換算成熟練度，不用重學。

> 給維護者：`KEY` 這個常數永遠不要改。改名字等於換一個抽屜，
> 舊資料還在但程式不會去看，使用者的感受就是「更新一次進度就沒了」。
> 要調整資料結構請加欄位，並在 `migrate()` 裡往前相容。

### 還是有可能不見的情況

| 情況 | 會怎樣 | 怎麼辦 |
| --- | --- | --- |
| 重新整理、改版、關掉再開 | ✅ 不受影響 | — |
| 換手機、手機壞掉 | ❌ 會不見 | 用備份檔 |
| 清除瀏覽器資料 | ❌ 會不見 | 用備份檔 |
| 用無痕模式打開 | ❌ 一關就沒 | 畫面會跳紅色警告 |
| **一下用 Chrome、一下用主畫面圖示** | ⚠️ 進度看起來不見 | 固定用同一個入口 |
| iPhone 超過幾週沒打開 | ⚠️ 可能被系統清掉 | 加到主畫面可降低風險 |

「一下用 Chrome、一下用主畫面圖示」這點要特別注意：
不同瀏覽器的儲存空間是各自獨立的，Chrome 裡的進度 Safari 看不到，
反過來也一樣。**請固定從主畫面的圖示進入。**

程式啟動時會呼叫 `navigator.storage.persist()`，
向瀏覽器申請不要自動清除資料。加到主畫面後核准機率較高。

### 為什麼「更新一次就要重學」不會再發生

`load()` 判斷的不是「有沒有這個名字」，而是「這個名字底下有沒有**真的進度**」。
只要目前的資料是空的，就會回頭去舊名字找有進度的版本接回來，
並且保留這台手機已經調好的字級與語速。
這樣即使某次意外寫入了一份空白狀態，也不會把既有進度永遠蓋住。

另外：

- 開頁時會實際寫一筆再讀回來，確認這台手機真的存得進去（存不進去馬上跳紅色警告，
  而不是等練完一課才發現全部白費）
- 切到背景、關掉分頁時都會再存一次

### 備份與還原

設定頁最下面有「備份進度（給家人用）」：

- **存一份備份檔** — 產生一個 `學國字備份-20260731.json`，傳到 LINE 或雲端保存
- **讀回備份檔** — 選擇備份檔還原，還原前會顯示「目前 N 課 / 備份檔 M 課」讓你確認

超過 14 天沒備份而且已經上完 3 課以上時，「紀錄」頁會出現提醒。

## 給家人的建議

1. 先陪長輩把「設定」調好：字體選「最大」、說話速度選「很慢」
2. 每天就按那顆綠色大按鈕上一課，不用自己找要練什麼
3. 隔天先按「今日複習」，把該複習的清掉，再上新的一課
4. 每天 10 分鐘比一次練半小時有效，「紀錄」頁可以看連續天數
5. 如果覺得寫字太累，可以到設定把「每一課要不要練寫字」關掉
